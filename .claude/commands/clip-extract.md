# /clip-extract
Vrewの字幕テキストからバズりそうな切り抜きポイントを抽出するコマンド。

## 対象
ぴょん切り抜き部屋【公認】（@pyon_clips / TikTok→YouTube Shorts）

## 使い方
Vrewで書き出した字幕テキストをそのまま貼り付けるだけ。

## 実行手順

### Step 0: テキスト受け取り
- Vrewから書き出した字幕テキストを受け取る
- 配信のジャンル（ゲーム実況 / 雑談 / コラボ など）を確認

### Step 1: バズ候補の抽出（報告してから選別）
以下の基準でタイムスタンプを抽出：

**🔥 最高優先（絶対使う）**
- 大爆笑・絶叫・予想外のリアクション
- 「え、何それ！？」となる瞬間
- 視聴者がコメントしたくなるシーン

**⭐ 高優先（使いたい）**
- テンポよく笑いが続く30〜60秒
- ぴょんちゃんの個性が光るシーン
- ゲームのクリア・失敗の瞬間

**📌 候補（尺次第で）**
- キャラクター説明・豆知識
- 視聴者との絡み

### Step 2: タイムスタンプ一覧出力
```
🔥 [00:12:34〜00:13:05] 「〇〇」→ △△するシーン（推定再生数：高）
⭐ [00:25:10〜00:25:50] 「〇〇」→ △△するシーン
📌 [00:45:20〜00:46:00] 「〇〇」→ △△するシーン
```

### Step 3: ショートタイトル案
各候補に対してYouTube Shorts向けタイトルを提案：
- 30文字以内
- 感情を動かすワード使用
- 「ぴょん」のキャラを活かした表現

### Step 4: 優先順位の最終提案
「今週のShortsにするなら上位3本」を推薦理由とともに提示。
