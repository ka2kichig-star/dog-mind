# /preflight
デプロイ前に lint → 型 → ビルド → テストを自動ループで潰すコマンド。

## 使い方
デプロイを実行する直前に、コード全体の安全性・整合性を確認するために使用してください。

## 実行手順

### Step 0: 状態引き継ぎ
- `AGENT_CONTEXT.md` を読んでプロジェクトの技術構成を把握
- 「現在の状態：〇〇」を報告してからプリフライトチェックに入る

### Step 1: 実行コマンドの定義・確認
- プロジェクトに応じて、以下の実行コマンドを特定する（利用できないステップはスキップする）
  1. **Lint**: `npm run lint` 等
  2. **型チェック**: `tsc --noEmit` 等
  3. **ビルド**: `npm run build` 等
  4. **テスト**: `npm run test` 等

### Step 2: チェック＆自動修正ループ (最大3回)
- 順にコマンドを実行していく：
  - **エラーなくパスした場合**: 次のステップへ進む
  - **エラーが発生した場合**:
    - エラー原因を分析し、対象ファイルを修正する
    - 修正後、再び該当チェック（または最初のチェック）からやり直す
    - 3回ループを繰り返しても解消しない場合は、エラー内容と修正履歴を報告してループを中断する

### Step 3: チェック結果の報告
- すべてのチェック結果（例: Lint: OK, Type: OK, Build: OK, Test: OK）を勝貴くんに報告する
- 問題が完全に解消したことを確認し、安全にデプロイ可能な状態であることを宣言する
