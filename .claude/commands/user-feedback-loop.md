# /user-feedback-loop
アプリのレビュー・問い合わせ・SNSの反応を集めて、改善ネタに変換するループ。
「ユーザーが本当に求めているもの」を開発に反映する。

## 実行手順

### Step 0: フィードバック源の確認
- どこから声を集めるか（アプリ内問い合わせ / SNS / レビュー / 直接DM）
- 対象プロジェクトを確認

### Step 1: 声の収集・貼り付け
ユーザーの声（問い合わせ・コメント・レビュー）を貼り付けてもらう。

### Step 2: 分類・分析（報告してから進む）
```
【多い要望】（複数人が言っている＝優先度高）
- 〇〇（X件）

【不満・バグ報告】
- 〇〇 → /debug-detective で対応推奨

【褒められた点】（伸ばすべき強み）
- 〇〇

【見当違い・対応不要】
- 〇〇（理由）
```

### Step 3: 改善アクション提案
声を実装タスクに変換：
- すぐ直すもの → /dev-loop
- 新機能化するもの → /feature-loop
- 発信ネタになるもの → /content-loop

### Step 4: 完了報告
優先度つきの改善リストと、最初に着手すべき1つを提示。
ポジティブな声は発信素材としてストック提案。
