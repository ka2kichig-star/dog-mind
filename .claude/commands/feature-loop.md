# /feature-loop
新機能のアイデアから実装・確認・保存まで全部回すループ。
「こんな機能ほしい」を言うだけで形になる。

## このループがやること
```
feature-sketch（設計→実装）
　↓
verify-app（動作確認）
　↓ 問題あり → feature-sketchで修正🔄（最大3回）
　↓ 問題なし
commit-push-pr（保存・反映）
　↓
完了報告
```

## 実行手順

### Step 0: アイデア受け取り
- 「こんな機能ほしい」をユーザーから受け取る
- `AGENT_CONTEXT.md` で既存機能との重複を確認
- 「現在の状態：〇〇」を報告してからループ開始

### Step 1: 設計・実装フェーズ
`/feature-sketch` の手順に従う：
- 設計案を出して**承認をもらってから**実装
- 修正したファイルを箇条書きで報告

### Step 2: 検証フェーズ
`/verify-app` の手順に従う：
- 新機能の動作 + 既存機能が壊れていないか確認
- **問題があればStep 1に戻る（最大3回）**

### Step 3: 保存フェーズ
`/commit-push-pr` の手順に従う。

### Step 4: ループ完了報告
```
✨ 新機能リリース完了
- 機能名：〇〇
- 実装ファイル：[一覧]
- 修正回数：X回
- 確認URL：〇〇
- 次に追加できる関連機能：[提案]
```
