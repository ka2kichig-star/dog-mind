# /content-loop
コンテンツのネタから投稿文・告知文まで一気に作る発信ループ。
「今日何発信しよう」を解決する。

## このループがやること
```
ネタ・素材を受け取る
　↓
threads-post（徳ポイント哲学で投稿文3パターン）
　↓
note-article（深掘りできるなら有料記事の構成案）
　↓
完了報告（今日の発信プラン）
```

## 実行手順

### Step 0: ネタ受け取り
- 発信したいネタ・テーマ・出来事をユーザーから受け取る
- 今日メインで使う媒体を確認（Threads / note / 両方）

### Step 1: Threads投稿生成フェーズ
`/threads-post` の手順に従う：
- 哲学系 / 日常系 / 行動促進系の3パターン生成
- 2.7万いいね実績のトーンを意識

### Step 2: note記事判定フェーズ
ネタが深掘りできるテーマか判定：
- **深掘りできる** → `/note-article` の構成案を生成
- **単発向き** → スキップして「これはThreads単発が最適」と報告

### Step 3: 発信プラン提案
```
📣 今日の発信プラン
- Threads：[選んだパターン]を朝に投稿
- note：[テーマ]を週末に展開（構成案あり）
- 連携：Threadsからnoteへの導線を〇〇で
```

### Step 4: ループ完了報告
コピペ用の完成文をまとめて出力。
