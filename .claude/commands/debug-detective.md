# /debug-detective
エラーメッセージ・スタックトレースを貼るだけで原因特定〜修正までやるコマンド。

## 使い方
エラーをそのままコピペして貼り付けるだけでOK。

## 実行手順

### Step 0: 状態引き継ぎ
- `AGENT_CONTEXT.md` を読んで現在のスタック・既知バグを把握
- エラーの発生状況（いつ・どの操作で起きるか）を確認
- 「現在の状態：〇〇」を報告してから調査に入る

### Step 1: エラー分類（報告してから進む）
貼り付けられたエラーを以下で分類：
- **Firebase系**：Auth / Firestore / Storage / Functions
- **Stripe系**：Webhook / 決済フロー / API
- **フロントエンド系**：React / DOM / 非同期
- **Cloud Run系**：デプロイ / コンテナ / 環境変数
- **ネットワーク系**：CORS / 認証トークン / タイムアウト

### Step 2: 根本原因の特定
エラーメッセージ + コードベースを照合して原因を特定。
「なぜそのエラーが出るか」を1〜3行で説明してから修正に入る。

### Step 3: 修正
- 最小限の変更で修正
- 修正したファイルを箇条書きで報告

### Step 4: 再発防止策の提案
同じエラーが起きないように：
- エラーハンドリングの追加
- バリデーションの追加
- コメントの追加

### Step 5: 完了報告
- 原因サマリー（1行）
- 修正内容
- 今後注意すべき点
