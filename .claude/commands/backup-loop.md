# /backup-loop
コード・データ・設定のバックアップ状況を点検して、消失リスクを下げるループ。
「PCが壊れた」「Firestoreを誤って消した」で全部失わないために。

## 実行手順

### Step 0: 対象確認
- バックアップ対象（コード / Firestore / 環境変数 / 画像）を確認

### Step 1: バックアップ状況チェック（報告してから進む）
- [ ] コードはGitHubにpush済みか（ローカルだけになっていないか）
- [ ] Firestoreの定期エクスポート設定があるか
- [ ] 環境変数・APIキーが安全な場所に控えてあるか
- [ ] 重要な画像・素材のバックアップがあるか
- [ ] C:\dev\ 全体のバックアップ手段があるか

### Step 2: 穴の特定
バックアップされていない危険な箇所を報告。

### Step 3: バックアップ実行・設定提案
- 未pushのコードをcommit-push
- Firestoreエクスポートコマンドの提案
- 環境変数の控え方を提案

### Step 4: 完了報告
```
💾 バックアップ点検完了
- 安全：〇〇
- 要対応：〇〇
- 推奨：定期バックアップの仕組み化
```
