# /verify-file
既存ファイルの構文・タグ・主要要素を検証する（変更しない）コマンド。

## 使い方
検証したいファイルのパスを指定してください。

## 実行手順

### Step 0: 状態引き継ぎ
- `AGENT_CONTEXT.md` を読んでプロジェクトの構成と目的を把握
- 検証対象のファイルパスを確認
- 「現在の状態：〇〇」を報告してから検証に入る

### Step 1: 構文・タグのチェック
- 対象ファイルを読み込み、シンタックスエラー（構文エラー）がないか確認する
- HTML/XML/TSXなどのマークアップ言語の場合、閉じタグの不足やネストの崩れがないかを厳密に確認する
- JS/TS/Pythonなどのスクリプト言語の場合、ブラケット・括弧の不整合や未定義の変数がないか確認する

### Step 2: 主要要素・セマンティクスの検証
- ファイルが果たすべき役割に応じた主要要素を検証する（例: Reactコンポーネントなら必須プロパティや正しいエクスポート、HTMLファイルなら適切なSEO用メタタグや `id` 属性など）

### Step 3: 品質・スタイルの簡易点検
- 不要な `console.log` やデバッグコード、未使用のインポートがないかを点検する
- **重要**: このコマンドではファイルへの変更（書き込み）は一切行わず、読み込みと検証のみにとどめる

### Step 4: 検証結果のレポート
- 発見された問題を「エラー（修正必須）」「警告（推奨改善）」に分けて勝貴くんに報告する
- 改善点がある場合は、具体的な修正コードの提案を添える
- 問題がなければ「検証パス」を報告する
