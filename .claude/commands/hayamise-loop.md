# /hayamise-loop
HAYAMISEの新規クライアント対応を生成から納品まで回すループ。
「サイト作って、確認して、お客さんに渡す」を一括。

## このループがやること
```
new-client-site（クライアントサイト生成・デプロイ）
　↓
verify-app（動作・表示確認）
　↓ 問題あり → new-client-siteで修正🔄
　↓ 問題なし
sales-assist（納品メッセージ・フォロー文生成）
　↓
完了報告
```

## 実行手順

### Step 0: クライアント情報受け取り
- 店舗名・業種・カラー・掲載内容・プランを確認
- 「現在の状態：〇〇」を報告してからループ開始

### Step 1: サイト生成フェーズ
`/new-client-site` の手順に従う：
- テンプレートからサイト生成 → デプロイ

### Step 2: 確認フェーズ
`/verify-app` の手順（Web版）に従う：
- モバイル表示・リンク・表示崩れをチェック
- **問題があればStep 1に戻る（最大2回）**

### Step 3: 納品メッセージフェーズ
`/sales-assist` の納品フェーズに従う：
- 「サイト完成しました」の納品メッセージ生成
- 月額プランの継続フォロー文も用意

### Step 4: ループ完了報告
```
🏢 HAYAMISE納品完了
- サイトURL：〇〇
- プラン：¥X,XXX/月
- 納品メッセージ：生成済み
- 次のアクション：クライアントへ送付
```
