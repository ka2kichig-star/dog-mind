# /monetize-loop
既存アプリ・コンテンツの収益化ポイントを点検して改善するループ。
「これ、もっとお金になるんじゃない？」を形にする。

## このループがやること
```
対象プロジェクトの現状分析
　↓
収益化の穴・改善点を洗い出し
　↓
最も効果が高い1つを実装（決済導線・課金ポイント・アフィリ）
　↓
verify-app（決済フロー確認）
　↓
完了報告（収益化ロードマップ）
```

## 実行手順

### Step 0: 対象確認
- どのプロジェクトの収益化を見るか確認
- `AGENT_CONTEXT.md` で現在の課金構造を把握
- 「現在の状態：〇〇」を報告してからループ開始

### Step 1: 収益化診断（報告してから進む）
以下の観点でチェック：

**💰 課金導線**
- [ ] 無料→有料の動機づけが明確か
- [ ] 決済までのステップが多すぎないか
- [ ] 価格が適切か（安すぎ/高すぎ）

**🔗 アフィリエイト**
- [ ] ペット系（わんにゃん翻訳機）にアフィリ余地はあるか
- [ ] A8.net等の導線を貼れる箇所はあるか

**📈 LTV向上**
- [ ] リピート・継続の仕掛けがあるか
- [ ] 解約を防ぐ要素があるか

### Step 2: 最優先施策の実装
効果 × 工数で一番おいしい1つを実装。
修正したファイルを箇条書きで報告。

### Step 3: 決済フロー確認
`/verify-app` の決済部分のみチェック。

### Step 4: ループ完了報告
```
💰 収益化改善完了
- 実装した施策：〇〇
- 期待効果：△△
【次の収益化ロードマップ】
1. [施策]（効果：高 / 工数：小）
2. [施策]
```
