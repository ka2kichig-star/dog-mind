# /safe-deploy-loop
デプロイ前にコードを健康診断してから安全にデプロイするループ。
「壊さずにデプロイする」を徹底する。

## このループがやること
```
code-health（技術的負債・危険箇所チェック）
　↓ 🔴があれば修正
deploy-check（デプロイ前の本番設定確認）
　↓ 問題あり → 止まって報告
　↓ 問題なし
commit-push-pr（デプロイ）
　↓
babysit（デプロイ見守り）
　↓
完了報告
```

## 実行手順

### Step 0: 状態引き継ぎ
- `AGENT_CONTEXT.md` を読んで現在の状態を把握
- デプロイ対象プロジェクトを確認
- 「現在の状態：〇〇」を報告してからループ開始

### Step 1: 健康診断フェーズ
`/code-health` の手順に従う：
- 🔴（APIキー露出・エラーハンドリング漏れ等）があれば即修正
- 🟡🟢はリスト化だけして次へ

### Step 2: デプロイ前確認フェーズ
`/deploy-check` の手順に従う：
- 環境変数・APIキー・本番URLの確認
- **問題があれば停止して報告**（危険なデプロイをしない）

### Step 3: デプロイフェーズ
`/commit-push-pr` の手順に従う。

### Step 4: 見守りフェーズ
`/babysit` の手順に従う：
- デプロイ完了まで監視

### Step 5: ループ完了報告
```
✅ 安全デプロイ完了
- 健康診断：🔴X件修正 / 🟡X件記録
- デプロイ：成功
- 本番確認URL：〇〇
```
