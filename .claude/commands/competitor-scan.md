# /competitor-scan
似たアプリ・サービス・発信者を調べて、自分の立ち位置と差別化点を見つけるコマンド。
「同じようなのもうあるかも」を確認して、勝てる切り口を探す。

## 実行手順

### Step 0: 対象確認
- 何の競合を調べるか（アプリ / コンテンツジャンル / サービス）
- 自分のプロジェクトの特徴を整理

### Step 1: 競合リサーチ（Web検索活用）
類似サービス・発信者を調査して報告：
- どんなものが既にあるか
- それぞれの強み・弱み
- 価格・収益モデル

### Step 2: 差別化ポイントの分析
```
【競合にあって自分にないもの】
- 〇〇（取り入れるべきか判断）

【自分にあって競合にないもの】← ここが武器
- 〇〇（土木専門 × AI、徳ポイント哲学など独自性）

【まだ誰もやっていない隙間】
- 〇〇
```

### Step 3: 勝てる切り口の提案
勝貴くんの強みを活かした差別化戦略を提案。

### Step 4: 完了報告
- ポジショニングの提案
- 次のアクション（/content-loop や /feature-loop へ橋渡し）
