# /zero-to-one-loop
新しいアプリ・ツールをアイデアから動くプロトタイプまで最速で立ち上げるループ。
「思いついたアプリを今日中に形にする」ためのやつ。

## このループがやること
```
アイデアを7項目に整理（量産テンプレv1.0ベース）
　↓
feature-sketch（コア機能の設計→実装）
　↓
verify-app（最低限動くか確認）
　↓ 問題あり → feature-sketchに戻る🔄
　↓ 問題なし
commit-push-pr（初回コミット・デプロイ）
　↓
完了報告（次にやることリスト）
```

## 実行手順

### Step 0: アイデア受け取り
以下7項目を埋める（未指定は一緒に決める）：
1. アプリ名
2. 一言説明
3. ターゲットユーザー
4. 入力（ユーザーが入れるもの）
5. 出力（アプリが返すもの）
6. 収益モデル（無料 / 月額 / 都度課金）
7. テーマカラー

「現在の状態：7項目確定」を報告してからループ開始。

### Step 1: コア機能の設計・実装
`/feature-sketch` の手順で**MVP（最小限動く版）だけ**作る：
- 入力フォーム
- 処理（Claude API / Firebase）
- 出力表示
- 凝りすぎない。まず動かす。

### Step 2: 動作確認
`/verify-app` の最低限版：
- 入力→処理→出力が一周するか
- **回らなければStep 1に戻る（最大3回）**

### Step 3: 初回デプロイ
`/commit-push-pr` で初回コミット → Firebase Hosting等へデプロイ。

### Step 4: ループ完了報告
```
🚀 ゼロイチ完了
- アプリ名：〇〇
- デプロイURL：〇〇
- 動く機能：[一覧]
【次にやること】
- [ ] デザイン洗練
- [ ] 決済追加（収益モデル：〇〇）
- [ ] LP作成 → /content-loop で告知
```
