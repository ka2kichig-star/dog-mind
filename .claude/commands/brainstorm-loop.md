# /brainstorm-loop
ぼんやりしたアイデアを壁打ちして具体的な企画まで落とすループ。
「なんか面白いことしたい」を形にする。

## このループがやること
```
ざっくりしたアイデア・興味を受け取る
　↓
複数の角度で広げる（10案出す）
　↓
ユーザーが選別
　↓
選んだものを企画に落とし込む
　↓
実装ループへの橋渡し
```

## 実行手順

### Step 0: テーマ受け取り
- ぼんやりした興味・やりたいこと・課題感を受け取る
- 勝貴くんの強み（土木専門 / AI開発 / バイク / 発信 / 徳ポイント哲学）と掛け合わせて考える

### Step 1: アイデア拡散（10案）
受け取ったテーマを以下の角度で広げる：
- アプリ・ツールにするなら？
- コンテンツ（Threads/note）にするなら？
- 既存プロジェクトと組み合わせるなら？
- 収益化するなら？

10案を一覧で提示（各案：何を / 誰に / どう稼ぐ を1行ずつ）。

### Step 2: 選別サポート
「勝貴くんの今のリソースで一番おいしいのはコレ」を3つに絞って推薦。

### Step 3: 企画化
選んだ案を具体化：
- ゴール
- 必要なもの
- 最初の一歩
- 使えるループ・コマンド

### Step 4: 実装への橋渡し
「これを作るなら /zero-to-one-loop」のように次のアクションを提示。
