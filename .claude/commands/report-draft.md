# /report-draft
現場メモから土木補修・調査の報告書ドラフトを生成するコマンド。

## 対象業務
スピードカッター / あと施工アンカー・コア削孔・鉄筋探査・樹脂注入・モルタル注入など

## 専門用語の補完ルール
- φ → 削孔径（mm）
- HL → ハンマードリル
- CD/CB → コアドリル（乾式/湿式）
- 注入 → 文脈によりエポキシ樹脂注入 / モルタル注入 / 止水注入
- 探査 → 電磁波レーダー法による鉄筋探査
- 不明略語は `[確認要]` を付記

## 実行手順

### Step 0: 状態引き継ぎ
- ユーザーから現場メモ・メモ書きを受け取る
- 不明点がある場合は調査前に確認する

### Step 1: 情報整理（報告してから進む）
以下を整理して報告：
- 工事名・現場名
- 作業日・担当者
- 作業内容の種別
- 数量・仕様
- 特記事項

### Step 2: 報告書ドラフト生成
```
### 1. 工事概要
[工事名・場所・日時]

### 2. 実施内容
| 作業項目 | 仕様 | 数量 | 備考 |
|---------|------|------|------|

### 3. 調査・施工結果
[結果・所見]

### 4. 特記事項
[注意点・懸念点・申し送り]

### 5. 使用機材・材料
[主要機材・材料]
```

### Step 3: 確認 & 完成
不明箇所をリストアップして確認後、最終版を出力。
