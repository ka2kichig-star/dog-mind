# /feature-sketch
「こんな機能ほしい」というアイデアを設計〜実装〜pushまで進めるコマンド。

## 実行手順

### Step 0: 状態引き継ぎ
- `AGENT_CONTEXT.md` を読んで現在のアーキテクチャを把握
- 既存機能との重複・競合を事前確認
- 「現在の状態：〇〇」を報告してから設計に入る

### Step 1: 要件ヒアリング
以下を確認（未指定なら確認する）：
- 何をしたいか（1文で）
- 誰が使うか（ユーザー / 管理者）
- どこに表示するか（画面・コンポーネント）
- 既存機能と繋がりがあるか

### Step 2: 設計案（承認もらってから実装）
```
機能名：
実装ファイル：
- 新規作成：xxx.tsx
- 変更：yyy.ts（〇〇を追加）
Firebase変更：Firestoreに〇〇コレクション追加 / なし
Stripe変更：なし / 〇〇
推定工数：小（30分） / 中（2時間） / 大（半日）
```

### Step 3: 実装
設計案を承認後に実装。
修正したファイルを箇条書きで報告。

### Step 4: 動作確認
実装後にセルフチェック：
- [ ] 基本動作が正常か
- [ ] エラー時の挙動が適切か
- [ ] モバイル表示が崩れていないか

### Step 5: Push
```bash
git add .
git commit -m "feat: [機能名] [簡潔な説明]"
git push origin main
```

### Step 6: 完了報告
- 実装内容サマリー
- 確認してほしいURL・画面
- 次に追加できる関連機能（提案）
