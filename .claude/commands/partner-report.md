# /partner-report

営業代行からの報告を整理し、KPI更新と次のアクションを決める。

## 目的

代行さんから受け取った報告（DM送信数・返信率・アポ獲得数など）を
構造化し、HAYAMISE側のKPIを更新、報酬計算 + 次週方針を決定。

## 前提

- /partner-brief で発注済み
- 代行さんからの報告（テキスト/スプレッドシート/CSV）を受領
- AGENT_CONTEXT.md に現在のKPI記録あり

## ヒアリング・受領項目

報告内容として確認する：

1. 実施件数
   - DM送信数 / 電話発信数 / 訪問数
2. 応答指標
   - 返信あり件数 / 返信内容の内訳
3. アポ獲得
   - 獲得件数 / 業種別 / 日時
4. 失注理由
   - 「興味なし」「予算なし」「他社利用中」など
5. 工数・所要時間
   - 報酬計算の根拠

## 実行手順

1. 報告データを読み取り構造化
2. 主要指標を計算
   - 返信率（返信÷送信）
   - アポ率（アポ÷送信）
   - 1アポあたりコスト
3. AGENT_CONTEXT.md のKPI更新
4. 失注理由のトップ3を抽出
   - 共通パターンあれば反論集に追加検討
5. 報酬計算
   - 成果報酬制：アポ数 × 単価
   - 時給制：時間 × 時給
   - 件数制：件数 × 単価
6. 代行さんへの返信文案
   - 報酬支払予定 + 次週の依頼内容 or 終了通知
7. 次週方針提案
   - DM文面改善
   - ターゲット業種変更
   - 別の代行も並行

## 報告ルール

- KPI更新前後を表で比較
- 失注理由トップ3
- 報酬計算詳細
- 代行への返信文案
- 次週アクション3つ

## 関連コマンド

- /weekly-review-loop（週次振り返り）
