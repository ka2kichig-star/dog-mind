# /new-client-site
HAYAMISEの新規クライアントサイトを生成してデプロイするコマンド。

## 対象プロジェクト
HAYAMISE（サロン・飲食店向けサブスク型Web制作サービス）

## 実行手順

### Step 0: 状態引き継ぎ
- `AGENT_CONTEXT.md` を読んで現在の状態を把握
- テンプレートの場所を確認
- 確認前に「現在の状態：〇〇」を報告する

### Step 1: クライアント情報の受け取り
以下を確認（未指定なら確認する）：
- 店舗名・業種（サロン / カフェ / 飲食店など）
- カラーテーマ・雰囲気
- 掲載コンテンツ（メニュー・営業時間・アクセスなど）
- プラン（¥2,200 / ¥3,850 / ¥6,600）

### Step 2: サイト生成
テンプレートをベースに以下を生成：
- `index.html`
- `style.css`（テーマカラー・フォント適用）
- 必要なコンテンツセクション

修正したファイルを箇条書きで報告。

### Step 3: デプロイ
```bash
git add .
git commit -m "feat: 新規クライアントサイト追加 [店舗名]"
git push origin main
```
GitHub Pages または指定ホスティングへデプロイ。

### Step 4: 完了報告
- 生成サイトのURL
- 次のステップ（クライアントへの納品・修正対応）
