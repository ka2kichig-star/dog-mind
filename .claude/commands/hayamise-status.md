# /hayamise-status

HAYAMISEプロジェクト全体のKPIと状態を集計して報告する。

## 目的

リード数・アポ数・成約数・MRR（月次経常収益）・契約者数を
スプレッドシート / CSV / メモから集計し、現状を可視化する。

## 前提

- AGENT_CONTEXT.md に各指標の参照先が記載されていること
- 必要に応じて勝貴くんに数値を直接ヒアリング

## 集計項目

1. リード関連
   - 累計リード数（final_leads_top.csv の合算）
   - 今月新規取得リード数
   - リードの業種別内訳

2. 営業活動
   - 今月DM送信数
   - 電話アプローチ数
   - アポ獲得数
   - アポ獲得率（%）

3. 成約・収益
   - 今月新規契約数
   - 累計契約数
   - プラン別内訳（ライト/スタンダード/プロ）
   - 月次経常収益（MRR）
   - 解約数・解約率

4. インフラ状況
   - Firebase Hosting 稼働状況
   - Places API 今月使用量と残クレジット
   - Anthropic API 使用量

## 実行手順

1. AGENT_CONTEXT.md から最新数値を取得
2. 不足分は勝貴くんにヒアリング
3. 前月比 / 目標比 を計算
4. ボトルネックを1つ指摘（最も改善余地が大きい指標）
5. 次の1週間でやるべきアクションを3つ提案

## 報告ルール

- 表形式で全KPIを一覧表示
- 良い指標は◎、改善が必要な指標は△で視覚化
- ボトルネック1つ + アクション3つで締める
- /weekly-review-loop と組み合わせて使うことを推奨

## 関連コマンド

- /weekly-review-loop（週次振り返り全体）
- /cost-check（インフラ費用詳細）
- /monetize-loop（収益化点検）
