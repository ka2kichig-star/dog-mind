# /command-cleanup
増えすぎたコマンドを整理・統廃合するメタコマンド。
使わないコマンドを削って、本当に使うものだけ残す。

## 実行手順

### Step 0: 全コマンド棚卸し
- 現在の全コマンドをリストアップ
- 各コマンドの最終使用状況を確認（覚えている範囲で）

### Step 1: 分類（報告してから進む）
```
【よく使う】（残す）
- 〇〇

【たまに使う】（残す）
- 〇〇

【使っていない】（削除 or 統合候補）
- 〇〇

【似ていて統合できる】
- 〇〇 と △△ → 1つにまとめられる
```

### Step 2: 統廃合の提案
- 削除候補とその理由
- 統合できるコマンドの組み合わせ

### Step 3: 承認後に整理
ユーザー確認後、不要なコマンドを削除・統合。

### Step 4: 完了報告
- 整理前後のコマンド数
- すっきりした構成
- 配布キット更新の提案
