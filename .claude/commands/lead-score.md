# /lead-score

取得済み店舗データをスコアリングし、営業対象を抽出する。

## 目的

`data/raw_places.json` を読み込み、「サイト無し × Web集客に困ってそう」
な店舗を点数化、優先度判定。

## 前提

- /lead-fetch 実行済み（raw_places.json 存在）
- AGENT_CONTEXT.md で「今日のターゲット業種」確認

## スコアリング基準

加点：
- websiteUri 空 / SNSのみ / 食べログ等 → +30
- レビュー50件以上 → +20
- ★4.0以上 → +10〜15
- 電話番号あり → +10
- 写真5枚以上 → +5〜10

減点：
- 大手チェーン名 → -50（除外）
- レビュー10件未満 → -20

判定：
- 60点以上 → 🎯営業対象
- 40-59点 → △二次候補
- 40点未満 → ✗除外

## 実行手順

1. raw_places.json のレコード数確認
2. `python 02_score_leads.py`
3. 検証
   - 🎯営業対象が想定範囲か
   - トップ5の妥当性目視
   - 大手チェーン正しく除外されているか

## 報告ルール

- 3区分（営業対象/二次候補/除外）の件数
- スコア上位5件の店舗名・スコア・サイト状況
- スコア分布の傾向
- 次は /lead-export または /dm-batch

## 関連コマンド

- /lead-fetch（前提）
- /lead-export（次）
- /dm-batch（DM生成まで一気に）
