# /repurpose-loop
1つのコンテンツを複数の媒体・形式に展開するループ。
「1回作って5回使う」で発信効率を最大化する。

## 実行手順

### Step 0: 元素材の確認
- 展開したい元コンテンツを確認（note記事 / 切り抜き / 開発の出来事など）

### Step 1: 展開先の洗い出し（報告してから進む）
1つの素材から何が作れるか：
- Threads投稿（短文・複数パターン）
- note記事（深掘り版）
- YouTube Shorts / TikTok（動画化）
- Instagram（ビジュアル版）
- DUSTEDの商品アイデア（バイク系なら）

### Step 2: 各媒体向けに変換
- `/threads-post` → Threads版
- `/note-article` → note版
- `/clip-loop` → 動画版（該当すれば）

### Step 3: 投稿順序・導線の設計
どの順番で出すと相互に流入を生むか提案：
```
Threads（フック）→ note（深掘り・有料）
　↓
切り抜き動画（拡散）→ プロフィールへ誘導
```

### Step 4: 完了報告
1素材から作った全コンテンツと、投稿スケジュール案を提示。
