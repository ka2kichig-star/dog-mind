# /code-health
プロジェクトのコードを健康診断して技術的負債・改善点をリストアップするコマンド。

## 実行手順

### Step 0: 状態引き継ぎ
- `AGENT_CONTEXT.md` を読んで現在の状態を把握
- 診断対象のプロジェクトを確認
- 「現在の状態：〇〇」を報告してから診断に入る

### Step 1: 構造診断（報告してから進む）
```bash
find . -name "*.ts" -o -name "*.tsx" | head -30
wc -l src/**/*.ts 2>/dev/null | sort -n | tail -10
```
- ファイル構成が適切か
- 肥大化しているファイルがないか（300行超）

### Step 2: 品質チェック
以下を確認して報告：

**🔴 即修正推奨**
- ハードコードされたAPIキー・シークレット
- エラーハンドリングなしの非同期処理
- コンソールログが本番コードに残っている

**🟡 近いうちに対応**
- 重複コード（同じロジックが2箇所以上）
- 型定義が`any`になっている箇所
- コメントが全くないcomplex関数

**🟢 余裕があれば**
- コンポーネントの分割が可能な箇所
- パフォーマンス改善の余地
- テストが書けそうな箇所

### Step 3: 優先修正
🔴の項目を即修正。
修正したファイルを箇条書きで報告。

### Step 4: 改善ロードマップ出力
🟡🟢の項目を優先度順にリスト化してAGENT_CONTEXT.mdに追記提案。

### Step 5: 完了報告
- 健康スコア（🔴件 / 🟡件 / 🟢件）
- 即修正した内容
- 次回の健康診断推奨タイミング
