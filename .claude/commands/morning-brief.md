# /morning-brief
今日やることを整理して、最短ルートでタスクを並べるコマンド。

## 実行手順

### Step 0: 状態引き継ぎ
- `AGENT_CONTEXT.md` を読んで各プロジェクトの現状を把握
- 今日の日付・曜日を確認

### Step 1: 状況ヒアリング
以下を確認（未指定なら確認する）：
- 今日の本業（土木）は何時まで？
- 娘・家族の予定はある？
- クレープ店の営業日？
- 締め切りが近いタスクはある？

### Step 2: 全プロジェクト状況サマリー（報告してから進む）
AGENT_CONTEXT.mdベースで各プロジェクトの緊急度を確認：

| プロジェクト | 直近のタスク | 緊急度 |
|------------|------------|--------|
| わんにゃん翻訳機 | 〇〇 | 🔴/🟡/🟢 |
| HAYAMISE | 〇〇 | 🔴/🟡/🟢 |
| RideConnect | 〇〇 | 🔴/🟡/🟢 |
| コンテンツ | 〇〇 | 🔴/🟡/🟢 |

### Step 3: 今日のタスクリスト生成
使える時間と緊急度から最適な順番でタスクを並べる：

```
【今日やること】
1. 🔴 [タスク名]（所要時間：〇分）→ /[使うコマンド]
2. 🟡 [タスク名]（所要時間：〇分）→ /[使うコマンド]
3. 🟢 [タスク名]（所要時間：〇分）→ /[使うコマンド]

【やらないこと（今日は手をつけない）】
- 〇〇（理由：△△）
```

### Step 4: 最初の一手を提示
「まず何から始めるか」を1つだけ明確に提示。
