# /hotfix-loop
本番で障害が起きたときに最速で修正・デプロイするループ。
「ユーザーが使えてない！」を最短で解決する。

## このループがやること
```
debug-detective（障害の原因を最速特定・修正）
　↓
最小限のverify（壊れてないか最低限チェック）
　↓
commit-push-pr（即デプロイ）
　↓
babysit（復旧確認まで見守り）
　↓
完了報告 + 再発防止メモ
```

## ⚠️ このループの方針
**スピード最優先。完璧より復旧。**
丁寧な検証より、まず動く状態に戻すことを優先する。

## 実行手順

### Step 0: 障害状況の把握
- 何が起きているか（ユーザーへの影響）を最速で確認
- 影響範囲（全ユーザー / 一部 / 特定機能）を報告

### Step 1: 緊急修正フェーズ
`/debug-detective` の手順を高速で：
- エラー特定 → 最小限の修正
- 大きなリファクタはしない（後回し）

### Step 2: 最低限チェック
- 修正箇所が動くか
- 他を壊していないか（主要機能のみ確認）

### Step 3: 即デプロイ
```bash
git add .
git commit -m "hotfix: [障害内容]"
git push origin main
```

### Step 4: 復旧確認フェーズ
`/babysit` で本番が復旧したか監視。

### Step 5: ループ完了報告 + 再発防止
```
🚨 緊急対応完了
- 障害内容：〇〇
- 復旧時刻：〇〇
- 応急処置：〇〇
- 【後でやる】根本対応：△△
- 再発防止策：□□
```
