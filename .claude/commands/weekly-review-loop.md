# /weekly-review-loop
週末に全プロジェクトを振り返って来週の計画を立てるループ。
「今週何進んだ？来週何やる？」を整理する。

## このループがやること
```
全プロジェクトのgit履歴・進捗を確認
　↓
code-health（主要プロジェクトの健康診断）
　↓
来週のタスク・優先順位を提案
　↓
AGENT_CONTEXT.mdへの更新提案
```

## 実行手順

### Step 0: 状態引き継ぎ
- 各プロジェクトの `AGENT_CONTEXT.md` を読む
- 今週の日付範囲を確認

### Step 1: 今週の振り返りフェーズ
各プロジェクトで実行：
```bash
git log --oneline --since="1 week ago"
```
- 今週進んだこと
- 止まっていること
- 残課題

### Step 2: 健康診断フェーズ
主要プロジェクト（わんにゃん翻訳機など）で `/code-health` を実施。

### Step 3: 来週の計画提案
```
📅 来週の計画
【最優先】〇〇（理由：△△）→ /[コマンド]
【中優先】〇〇
【調整中】〇〇

【先送り判断】
- 〇〇は来週も手をつけない（理由）
```

### Step 4: AGENT_CONTEXT更新提案
各プロジェクトのコンテキストファイルに追記すべき内容を提案。

### Step 5: ループ完了報告
今週のサマリー + 来週の最初の一手を提示。
