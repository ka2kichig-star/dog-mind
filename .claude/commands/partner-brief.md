# /partner-brief

営業代行（ココナラ・クラウドワークス等）への発注文を生成する。

## 目的

リードCSV + ツールキットURL + DM文面 + 報酬条件をセットにした
発注文を、依頼プラットフォーム別に最適化して出力。

## 前提

- /lead-loop 完了済み
- HAYAMISEツールキットURL（パスワード付き）が用意済み
- 報酬条件（時給/件数単価/成果報酬）を勝貴くんが決めている

## ヒアリング項目

最初に勝貴くんに確認する：

1. 依頼先プラットフォーム
   - ココナラ / クラウドワークス / ランサーズ / その他
2. 依頼内容
   - DM送信代行 / 電話アポ取り / フル営業
3. 件数
   - 100件 / 300件 / 制限なし
4. 報酬体系
   - 時給制 / 件数単価 / 成果報酬（アポ獲得時のみ）
5. 期限
   - 1週間 / 1ヶ月 / 継続

## 生成する発注文の構成

1. 件名（プラットフォーム別に最適化）
2. 自己紹介・サービス概要
3. 依頼内容詳細
   - 何をしてほしいか
   - 何をしてほしくないか（NG行動）
4. 提供物
   - ツールキットURL + パスワード
   - リードCSV
   - DMテンプレート
5. 報酬・支払条件
6. 期限・連絡頻度
7. 求める人物像

## 守るべきこと

- 個人情報・APIキーは絶対に含めない
- ツールキットのパスワードは別途連絡する旨を明記
- HAYAMISE のブランド毀損リスクのある行動（スパム的なDM）を禁止条項に

## 報告ルール

- プラットフォーム別の発注文（コピペ可能）
- 想定応募者数・コスト見積もり
- 採用基準のチェックリスト
- 次は /partner-report（受領後の管理）

## 関連コマンド

- /lead-loop（リード生成）
- /dm-batch（DM文面準備）
- /partner-report（代行報告整理）
