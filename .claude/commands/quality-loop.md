# /quality-loop
アプリの品質を多角的にチェックして底上げするループ。
リリース前じゃなくても定期的に品質を保つためのやつ。

## このループがやること
```
verify-app（機能チェック）
　↓
code-health（コード品質チェック）
　↓
エラーハンドリング・UX・パフォーマンスの穴を特定
　↓
優先度高い問題を修正
　↓
commit-push-pr（保存）
　↓
完了報告（品質スコア）
```

## 実行手順

### Step 0: 状態引き継ぎ
- `AGENT_CONTEXT.md` を読んで現在の状態を把握
- 対象プロジェクトを確認
- 「現在の状態：〇〇」を報告してからループ開始

### Step 1: 機能品質チェック
`/verify-app` の手順で全機能をチェック。

### Step 2: コード品質チェック
`/code-health` の手順で技術的負債をチェック。

### Step 3: UX・体験品質チェック（独自）
- [ ] 初見ユーザーが迷わず使えるか
- [ ] エラー時に何をすべきか分かるか
- [ ] ローディングが長すぎないか
- [ ] モバイルで操作しづらい箇所がないか

### Step 4: 優先修正
🔴の問題を修正 → `/commit-push-pr` で保存。

### Step 5: ループ完了報告
```
🎯 品質チェック完了
- 機能：✅X / ⚠️X / ❌X
- コード：🔴X / 🟡X / 🟢X
- UX：[気づき]
- 総合品質スコア：A / B / C
- 修正した内容：〇〇
```
