# /release-note
gitのコミット履歴からリリースノートを自動生成するコマンド。

## 実行手順

### Step 0: 状態引き継ぎ
- `AGENT_CONTEXT.md` を読んで現在のバージョン・リリース状況を把握
- 「現在の状態：〇〇」を報告してから生成に入る

### Step 1: コミット履歴取得
```bash
git log --oneline --since="2 weeks ago"
# または
git log --oneline [前回タグ]..HEAD
```

### Step 2: 変更内容の分類（報告してから進む）
コミットを以下に分類：
- ✨ 新機能
- 🐛 バグ修正
- 🎨 UI改善
- ⚡ パフォーマンス改善
- 🔒 セキュリティ修正
- 🗑️ 削除・廃止

### Step 3: リリースノート生成（3パターン）

**①ユーザー向け（アプリ内通知・SNS用）**
技術用語なし・メリット訴求・絵文字あり

**②GitHub Release用**
技術的詳細あり・Markdown形式

**③Threads/SNS告知用**
300文字以内・バージョンアップ感を演出

### Step 4: バージョン番号提案
セマンティックバージョニングに基づいて提案：
- Major（破壊的変更）: x.0.0
- Minor（新機能）: 0.x.0
- Patch（バグ修正）: 0.0.x

### Step 5: 完了報告
3パターンをコピペ用で出力。
