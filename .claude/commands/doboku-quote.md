# /doboku-quote
土木補修・調査の見積もりや数量計算をサポートするコマンド。
現場の条件から概算を素早く出す。

## 対象業務
あと施工アンカー、コア削孔、ドリル削孔、鉄筋探査、樹脂/モルタル注入など

## 実行手順

### Step 0: 案件情報の受け取り
以下を確認（未指定なら聞く）：
- 作業種別（コア削孔 / アンカー / 探査 / 注入など）
- 数量・規模（削孔本数・径・深さ、探査面積など）
- 現場条件（高所・狭所・夜間など）
- 材料の指定

### Step 1: 数量整理（報告してから進む）
```
作業項目：〇〇
仕様：φ〇〇 × 深さ〇〇
数量：〇〇本 / 〇〇m²
特殊条件：〇〇
```

### Step 2: 概算サポート
- 標準的な歩掛りの考え方を提示（※実際の単価は会社基準に従う）
- 数量計算の確認
- 見落としがちな項目（足場・養生・産廃処理など）のチェック

### Step 3: 完了報告
- 整理した数量表
- 見積もりに含めるべき項目リスト
- [確認要]の箇所を明記

## 注意
実際の単価・歩掛りはスピードカッターの社内基準が優先。
このコマンドは整理・抜け漏れ防止のサポート。
