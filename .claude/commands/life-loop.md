# /life-loop
仕事じゃない生活・家族まわりのタスクを整理して回すループ。
クレープ店・家庭菜園・娘との時間・バイクなど。

## このループがやること
```
今ある生活タスクを洗い出し
　↓
緊急度・重要度で整理
　↓
リマインダー・カレンダー登録を提案
　↓
完了報告
```

## 実行手順

### Step 0: 状況確認
以下を確認（未指定なら聞く）：
- 今日・今週の家族の予定
- クレープ店「ろじうら」の営業・仕込み
- 家庭菜園（ミニトマト・じゃがいも・ミョウガ等）の世話
- バイク関連（メンテ・ツーリング計画）

### Step 1: タスク整理（報告してから進む）
```
【家族・娘（泰央ちゃん）】
- 〇〇

【クレープ店】
- 〇〇

【家庭菜園】
- 〇〇（季節の作業：収穫・水やり・植え替え）

【バイク・趣味】
- 〇〇
```

### Step 2: 優先順位づけ
今週中にやるべきこと / 後でいいことに分類。

### Step 3: リマインダー提案
登録すべきものをリマインダー・カレンダーに入れる提案。
（ユーザー承認後に登録）

### Step 4: ループ完了報告
今週の生活タスクサマリーと「まず何からやるか」を提示。
