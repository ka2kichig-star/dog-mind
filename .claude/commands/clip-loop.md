# /clip-loop
ぴょん切り抜きの素材選定からタイトル・投稿まで回すループ。
「字幕貼るだけで今週のShorts候補が決まる」状態にする。

## このループがやること
```
clip-extract（Vrew字幕からバズ候補抽出）
　↓
ユーザーが候補を選別
　↓
threads-post（切り抜き告知のSNS文を生成）
　↓
完了報告（今週のShorts制作プラン）
```

## 実行手順

### Step 0: 素材受け取り
- Vrewから書き出した字幕テキストを受け取る
- 配信のジャンルを確認

### Step 1: バズ候補抽出フェーズ
`/clip-extract` の手順に従う：
- 🔥⭐📌の3段階でタイムスタンプ抽出
- 各候補にShortsタイトル案

### Step 2: 選別サポート
「今週のShortsにするなら上位3本」を理由つきで推薦。
ユーザーが選んだものを確定。

### Step 3: 告知文生成フェーズ
選んだ切り抜きの告知文を生成：
- YouTube Shorts説明欄用
- Threads/X告知用（ぴょんちゃんの個性を活かす）

### Step 4: ループ完了報告
```
✂️ 今週のShortsプラン
1. [タイトル] [タイムスタンプ]
2. [タイトル] [タイムスタンプ]
3. [タイトル] [タイムスタンプ]
- 編集フロー：Vrewカット → CapCut → HandBrake圧縮
- 告知文：生成済み
```
