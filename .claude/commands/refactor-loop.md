# /refactor-loop
動いてるけど汚いコードを安全に整理するループ。
「動くけどぐちゃぐちゃ」を「動くしキレイ」にする。

## このループがやること
```
code-health（リファクタ対象の特定）
　↓
1箇所ずつ安全にリファクタ
　↓
verify-app（壊れてないか毎回確認）
　↓ 壊れた → 即ロールバック🔄
　↓ OK
commit-push-pr（小さくこまめにコミット）
　↓
完了報告
```

## ⚠️ 方針
**動いているものを壊さない。** 一度に大きく変えず、小さく刻んで毎回確認する。

## 実行手順

### Step 0: 状態引き継ぎ
- `AGENT_CONTEXT.md` を読んで現在の状態を把握
- リファクタ対象を確認
- 「現在の状態：〇〇」を報告してからループ開始

### Step 1: 対象特定フェーズ
`/code-health` で整理すべき箇所をリスト化：
- 重複コード
- 肥大化した関数・ファイル
- any型・マジックナンバー

### Step 2: 1箇所ずつリファクタ
**1回のループで1箇所だけ**直す：
- リファクタ → `/verify-app` で確認 → OKならコミット
- **壊れたら即ロールバック**して原因報告
- 次の箇所へ

### Step 3: 段階的コミット
各リファクタごとに小さくコミット：
```bash
git commit -m "refactor: [何を整理したか]"
```

### Step 4: ループ完了報告
```
🧹 リファクタ完了
- 整理した箇所：X件
- 各コミット：[一覧]
- 残りの改善候補：[リスト]
- 動作：全機能正常確認済み
```
