# /traffic-loop
アプリ・サイトへの流入を増やすための施策を点検・実装するループ。
「作ったけど誰も来ない」を解決する。

## このループがやること
```
現状の流入経路を分析（GA4 / Clarity）
　↓
流入の穴を特定
　↓
SEO・SNS導線・LPの改善を実装
　↓
完了報告（流入改善プラン）
```

## 実行手順

### Step 0: 対象確認
- どのプロジェクトの流入を見るか確認
- GA4（G-MHNSHFCRMV）・Clarity（x0ebo717fq）のデータがあれば参照
- 「現在の状態：〇〇」を報告してからループ開始

### Step 1: 流入診断（報告してから進む）

**🔍 SEO基礎**
- [ ] titleタグ・meta descriptionが適切か
- [ ] OGP（SNSシェア時の表示）が設定されているか
- [ ] 構造化データ・サイトマップがあるか

**📱 SNS導線**
- [ ] Threads/Instagramからの導線があるか
- [ ] シェアしたくなる仕掛けがあるか

**🎯 LP・入口**
- [ ] ファーストビューで価値が伝わるか
- [ ] CTAが明確か

### Step 2: 最優先施策の実装
一番流入に効く改善を1つ実装（OGP設定・meta最適化など）。
修正したファイルを箇条書きで報告。

### Step 3: 告知文の生成
改善したら `/threads-post` で告知文も用意。

### Step 4: ループ完了報告
```
📈 流入改善完了
- 実装：〇〇
- 告知文：生成済み
【次の流入施策】
1. [施策]
2. [施策]
```
