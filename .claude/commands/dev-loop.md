# /dev-loop
バグ修正→動作確認→保存まで自動で回す開発ループ。
「コード直して、問題ないか確認して、保存する」を1コマンドで。

## このループがやること
```
debug-detective（バグ特定・修正）
　↓
verify-app（動作チェック）
　↓ 問題あり → debug-detectiveに戻る🔄（最大3回）
　↓ 問題なし
commit-push-pr（保存・リモート反映）
　↓
完了報告
```

## 実行手順

### Step 0: 状態引き継ぎ
- `AGENT_CONTEXT.md` を読んで現在の状態・既知バグを把握
- 直すバグ・エラーをユーザーから受け取る
- 「現在の状態：〇〇」を報告してからループ開始

### Step 1: バグ修正フェーズ
`/debug-detective` の手順に従う：
- エラー分類 → 根本原因特定 → 修正
- 修正したファイルを箇条書きで報告

### Step 2: 検証フェーズ
`/verify-app` の手順に従う：
- ビルドチェック + 機能チェックリスト
- **問題が見つかったらStep 1に戻る（最大3回まで）**
- 3回試してもダメなら正直に「自力解決できない」と報告して止まる

### Step 3: 保存フェーズ
検証OKになったら `/commit-push-pr` の手順に従う：
- 変更ファイル報告 → コミット → push

### Step 4: ループ完了報告
```
🔄 ループ完了
- 修正回数：X回
- 修正内容：〇〇
- コミット：[ハッシュ]
- 残課題：なし / 〇〇
```
