# /security-check
個人開発アプリのセキュリティ穴を点検するコマンド。
「APIキー漏洩」「誰でもデータ書き換え可能」みたいな事故を防ぐ。

## 実行手順

### Step 0: 状態引き継ぎ
- `AGENT_CONTEXT.md` で構成を把握
- 対象プロジェクトを確認

### Step 1: 危険箇所スキャン（報告してから進む）

**🔑 秘密情報の漏洩**
- [ ] APIキー・シークレットがコードに直書きされていないか
- [ ] .envがgitignoreされているか
- [ ] フロントエンドに秘密鍵が露出していないか（Stripe秘密鍵など）

**🔒 Firebaseルール**
- [ ] Firestoreルールが「誰でも読み書き可」になっていないか
- [ ] Storageルールが緩すぎないか
- [ ] 認証なしでアクセスできる危険なエンドポイントがないか

**🛡️ 入力検証**
- [ ] ユーザー入力のバリデーションがあるか
- [ ] SQLインジェクション・XSSの余地がないか

### Step 2: 緊急度判定
- 🔴 今すぐ直すべき（秘密鍵露出・ルール開放）
- 🟡 近いうちに対応
- 🟢 余裕があれば

### Step 3: 🔴の即修正
危険度の高いものをその場で修正。
修正したファイルを箇条書きで報告。

### Step 4: 完了報告
```
🛡️ セキュリティ点検結果
- 🔴修正済み：X件
- 🟡要対応：X件
- 総合リスク：高 / 中 / 低
```
