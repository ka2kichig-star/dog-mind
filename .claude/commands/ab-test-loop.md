# /ab-test-loop
価格・LP・ガチャ確率・コピーなどを2案で比較して、数字で勝ち負けを判断するループ。
「なんとなく」じゃなく「データで」改善する。

## 対象
ラーメンガチャの当たり確率、HAYAMISEの価格、LPのキャッチコピーなど

## 実行手順

### Step 0: 検証対象の確認
- 何をA/Bテストするか（価格 / コピー / 確率 / ボタン位置など）
- 成功指標は何か（登録率 / 課金率 / 滞在時間など）

### Step 1: 仮説設定（報告してから進む）
```
検証項目：〇〇
A案（現状）：〇〇
B案（新案）：〇〇
仮説：B案のほうが△△だから□□が上がるはず
測定指標：〇〇
```

### Step 2: 実装
両案を切り替えられる形で実装（フラグ・条件分岐など）。
GA4 / Clarityで計測できるようにイベント設定。

### Step 3: 判定基準の設定
- 何日 / 何人集まったら判定するか
- 有意な差とみなす基準

### Step 4: 完了報告
```
🔬 A/Bテスト準備完了
- 検証：A案 vs B案
- 測定方法：〇〇
- 判定タイミング：〇〇
→ データ集まったらまた /ab-test-loop で結果分析
```

## 結果分析モード（データが集まったら）
数字を貼り付けると、どっちが勝ったか・次に何を試すかを提案。
