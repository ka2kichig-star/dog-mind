# /update-lp
HAYAMISEのセールスページを更新してpushするコマンド。

## 対象プロジェクト
HAYAMISE（サロン・飲食店向けサブスク型Web制作サービス）

## 実行手順

### Step 0: 状態引き継ぎ
- `AGENT_CONTEXT.md` を読んで現在の状態を把握
- 現在のLPファイル構成を確認
- 確認前に「現在の状態：〇〇」を報告する

### Step 1: 更新内容の確認
ユーザーから以下を受け取る（未指定なら確認する）：
- どのセクションを更新するか（料金・実績・CTA・キャッチコピーなど）
- 変更の目的（コンバージョン改善・情報更新・デザイン修正）

### Step 2: 修正
- 対象セクションを修正
- 修正したファイルを箇条書きで報告：
  - `変更ファイル: index.html` など

### Step 3: Push
```bash
git add .
git commit -m "update: HAYAMISE LP [更新内容]"
git push origin main
```

### Step 4: 完了報告
- 更新内容サマリー
- A/Bテストや改善提案（あれば）
