# /parallel-task
タスクを独立サブタスクに分割して並列実行・集約するコマンド。

## 使い方
並列で実行・処理したい大きなタスク、または複数の対象ファイルを指定してください。

## 実行手順

### Step 0: 状態引き継ぎ
- `AGENT_CONTEXT.md` を読んでプロジェクトの現状と目的を把握
- ユーザーから並列処理したい大元のタスクを受け取る
- 「現在の状態：〇〇」を報告してから設計に入る

### Step 1: タスクの分割と依存関係の整理
- 大きなタスクを、互いに依存しない**独立したサブタスク**（目安3〜4個以内）に分解する
- 各サブタスクの「必要なインプット（前提）」と「出力される成果物（アウトプット）」を定義する

### Step 2: 並列実行プランの作成
- 各サブタスクの実行方法（どのファイルを操作するか、どのツールを使用するか）を定義した実行プランを提示する

### Step 3: 各サブタスクの実行と管理
- 順次、またはバックグラウンド処理（必要に応じてサブエージェント等）を活用し、サブタスクを並行または高速に実行する
- 各タスクの進捗ステータス（準備中 / 実行中 / 完了 / エラー）をリアルタイムに進捗報告する

### Step 4: 結果の集約と検証
- すべてのサブタスクから得られた成果物・コードを集約し、1つの機能またはファイルへ統合（マージ）する
- 統合によって不整合や競合が発生していないかを静的に検証する

### Step 5: 完了報告
- 各サブタスクの実行結果と、統合された最終成果物の状態を勝貴くんに報告する
