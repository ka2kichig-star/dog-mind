# /setup-loop
新しいプロジェクトの開発環境・コンテキストを整えるループ。
「新規プロジェクトをすぐ開発できる状態にする」ためのやつ。

## このループがやること
```
プロジェクト構造の確認・整理
　↓
AGENT_CONTEXT.md の作成・更新
　↓
.claude/commands の配置確認
　↓
walkthrough.md の生成
　↓
完了報告（開発準備完了）
```

## 実行手順

### Step 0: プロジェクト確認
- 対象プロジェクトのルートを確認
- 既存ファイル構造を `ls` で把握

### Step 1: コンテキストファイル整備（報告してから進む）
`AGENT_CONTEXT.md` を作成または更新：
```markdown
# プロジェクト名

## 技術スタック
[Firebase / React / Stripe など]

## 現在の状態
[何が動いていて、何が未完成か]

## 既知の課題
[未解決バグ・TODO]

## 重要な制約
[触ってはいけない箇所・注意点]
```

### Step 2: コマンド配置確認
- `.claude/commands/` にこのプロジェクトに必要なコマンドがあるか確認
- 不要なコマンド（例：土木系プロジェクトに report-draft 以外のWeb系）は整理を提案

### Step 3: walkthrough.md 生成
新規タブ読み込み用のガイドを作成：
```markdown
# walkthrough
## このプロジェクトで最初に読むもの
1. AGENT_CONTEXT.md（状態把握）
2. [主要ファイル]

## よく使うコマンド
- /[コマンド]：〇〇するとき
```

### Step 4: ループ完了報告
```
🛠️ 環境整備完了
- AGENT_CONTEXT.md：作成/更新済み
- 配置コマンド：[一覧]
- walkthrough.md：生成済み
→ これで開発開始できます
```
