# /fact-check
主張・数値・競合情報を出典つきで真偽判定するコマンド。

## 使い方
ファクトチェックしたいテキスト、データ、または競合情報を貼り付けてください。

## 実行手順

### Step 0: 状態引き継ぎ
- `AGENT_CONTEXT.md` を読んで現在のプロジェクトの状況を把握
- ユーザーから提示されたファクトチェック対象（主張、数値、競合他社の情報など）を確認
- 「現在の状態：〇〇」を報告してから調査に入る

### Step 1: 調査項目の整理
- 提示されたテキストから、ファクトチェックが必要な具体的な主張や数値を抽出してリスト化する
- 例：「 Firebase の無料枠枠内かどうか 」「 競合サービスの月額料金 」「 該当技術の対応ブラウザ 」など

### Step 2: 信頼性の高い一次ソースの調査
- 信頼できる一次情報源を調査する（公式ドキュメント、公式リリース、GitHub、信頼できる技術ブログなど）
- 必要に応じて web 検索を行い、最新の情報および複数のソースを確認する

### Step 3: 真偽判定とエビデンス整理
- 整理した項目ごとに、以下の判定を下す：
  - **【正 (True)】**: 信頼できる出典があり、正しいと確認された情報
  - **【誤 (False)】**: 明らかな誤り、または古い情報であると確認された情報
  - **【判定不能 (Unverified)】**: 出典が見つからない、または裏付けが不十分な情報
- すべての判定において、必ず**具体的な出典URL**または**公式ドキュメントの該当箇所の引用**をエビデンスとして添える

### Step 4: 結果の報告
- 判定結果を表形式、または見やすい箇条書きで整理し、勝貴くんに報告する
- 誤りがあった場合は、正しい数値・情報に書き換えた推奨テキストを併せて提示する
