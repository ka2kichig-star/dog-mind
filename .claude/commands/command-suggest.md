# /command-suggest
今の勝貴くんの状況に対して「次に作るべきコマンド」を提案するメタコマンド。
なおやくんの「今の自分に必要なコマンドをClaudeに聞いてみて」を仕組み化したもの。

## 実行手順

### Step 0: 現状把握
- 今アクティブなプロジェクト・課題を確認
- 既存のコマンド一覧を踏まえる（重複を避ける）

### Step 1: 作業パターンの分析
最近の勝貴くんの動きから、繰り返している作業・手間を特定：
- 何度も手で同じことをしていないか
- コマンド化できる定型作業はないか
- 既存コマンドの組み合わせ（ループ化）で楽になるものはないか

### Step 2: 新コマンド候補の提案（3〜5個）
```
【提案1】/〇〇
- 解決する手間：〇〇
- 効果：〇〇
- 既存コマンドとの違い：〇〇
```

### Step 3: 優先順位づけ
「今作ると一番効くのはコレ」を理由つきで推薦。

### Step 4: そのまま作成
承認されたら即コマンドを作成 → 配布キットの_command_sourceに追加提案。
