# /objection-handle

営業中に出てきた反論・断り文句に対し、最適な返し方を提案する。

## 目的

DM返信や電話・対面で出た「断り文句」を貼り付けると、
HAYAMISE営業ツールキットの反論対応集に基づいて最適な返しを生成する。

## 前提

- 反論内容（相手の発言）を勝貴くんから受け取る
- 文脈（DM/電話/対面、相手の業種）も可能なら確認

## 実行手順

1. 反論内容の解析
   - 貼り付けられた文章を読む
   - 表面的な内容と本音（背景にある懸念）を分けて整理

2. 既存反論集との照合
   - sales-toolkit.html に同じパターンがあるか確認
   - ある場合：そのテンプレ + 今回の文脈に合わせた微調整
   - ない場合：原則に従って新規生成

3. 3パターン提案
   - 共感型（柔らかく寄り添う）
   - 論理型（数字・実例で返す）
   - 切り返し型（質問で返す）

4. 推奨パターン提示
   - 相手の業種・関係性から1つおすすめ

## 守るべきトーン

- 売り込みすぎない
- 相手の意見を否定しない
- 「おっしゃる通り」「承知しました」で受け止めてから返す
- 最終的なゴールは「LINE登録 / 無料相談」

## 報告ルール

- 反論内容の解釈を1行で
- 3パターンの返し文（コピペ可能な形式）
- おすすめパターンと理由
- もし新パターンを発見したらツールキットに追加するか確認

## 関連コマンド

- /sales-assist（営業文全般）
- /dm-batch（DM初回送信）
