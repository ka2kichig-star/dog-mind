# /learn-loop
新しい技術・ツール・概念を勝貴くんのペースで学ぶループ。
独学でスキルを積み上げてきたスタイルを加速する。

## 実行手順

### Step 0: 学びたいことの確認
- 何を学びたいか（新しいAPI / フレームワーク / AIツールなど）
- 今の理解度（全くの初心者 / なんとなく分かる）

### Step 1: 全体像の提示（報告してから進む）
- それが何なのか（身近なたとえで）
- なぜ勝貴くんに役立つか（既存プロジェクトとの関連）
- 学ぶ順番（最短ルート）

### Step 2: 実践ファースト
読むだけじゃなく、勝貴くんのプロジェクトで実際に試せる
小さな例を用意（手を動かして覚える）。

### Step 3: つまずきポイントの先回り
初心者がハマりやすい箇所を事前に警告。

### Step 4: 完了報告
- 今日理解したこと
- 次に学ぶべきこと
- 実プロジェクトへの応用アイデア
