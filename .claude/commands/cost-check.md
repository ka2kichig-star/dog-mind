# /cost-check
Firebase / Cloud Run / Claude APIなどの利用コストを点検して、想定外の課金を防ぐコマンド。
個人開発で地味に怖い「気づいたら高額請求」を未然に防ぐ。

## 実行手順

### Step 0: 状態引き継ぎ
- `AGENT_CONTEXT.md` で使っているサービスを把握
- どのプロジェクトのコストを見るか確認

### Step 1: コスト発生源の洗い出し（報告してから進む）
- [ ] Firebase（Firestore読み書き / Storage / Hosting転送量）
- [ ] Cloud Run（インスタンス稼働時間・メモリ）
- [ ] Claude API（トークン消費量・呼び出し回数）
- [ ] Stripe（手数料）
- [ ] その他外部API（fal.ai等）

### Step 2: 危険ポイントの特定
コストが跳ねやすい箇所をチェック：
- 無限ループ・無駄なAPI呼び出しがないか
- Firestoreの読み込みが過剰な箇所はないか
- 画像・動画の保存サイズが最適化されているか
- Claude APIに毎回長いコンテキストを送っていないか

### Step 3: 節約施策の提案
効果が大きい順に提案：
- キャッシュ導入
- API呼び出しのバッチ化
- 不要なログ・保存の削除

### Step 4: 完了報告
```
💰 コスト点検結果
- 主なコスト源：〇〇
- 危険ポイント：[あれば]
- 推奨節約策：[優先順]
- 想定削減額：月〇円
```
