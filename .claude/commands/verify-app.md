# /verify-app
アプリの全機能を検証してリリース判定を出すコマンド。

## 実行手順

### Step 0: 状態引き継ぎ
- `AGENT_CONTEXT.md` を読んで現在の状態・直近の変更を把握
- 検証対象のプロジェクト・バージョンを確認
- 「現在の状態：〇〇」を報告してから検証に入る

### Step 1: コード静的チェック（報告してから進む）
```bash
npm run build 2>&1 | tail -20
```
- TypeScriptエラーがないか
- 未使用のimportや明らかなバグがないか

### Step 2: 機能チェックリスト（全項目○×で報告）

**🔐 認証**
- [ ] 通常ブラウザでのGoogle認証
- [ ] WebView（Instagram/LINE/Threads）でのsignInWithRedirect
- [ ] ログアウト・セッション切れの挙動

**💳 Stripe決済**
- [ ] 月額プランの購入フロー完走
- [ ] checkout.session.completed → isPremium反映
- [ ] キャンセル → isPremium解除
- [ ] Webhookのログに正常受信が記録されているか

**🗄️ Firebase**
- [ ] Firestore read/writeが正常（セキュリティルール含む）
- [ ] Storage画像アップロードが正常
- [ ] Cloud Functionsが正常レスポンスを返しているか

**🐾 アプリ固有機能**
- [ ] ペット診断フローが最後まで動く
- [ ] 猫診断モードが正常動作
- [ ] 診断履歴の保存・表示
- [ ] チップ選択ボタンが消えていないか

**📱 UI/UX**
- [ ] モバイル表示が崩れていない
- [ ] ローディング・エラー状態が適切に表示
- [ ] LP → 登録 → 診断のファネルに詰まりがないか

### Step 3: 問題対応
発見した問題を優先度別に修正。
修正したファイルを箇条書きで報告。

### Step 4: リリース判定
```
✅ 正常：XX項目
⚠️ 軽微：XX項目（リリース後対応可）
❌ ブロッカー：XX項目（修正必須）

判定：GO ✅ / HOLD ❌
```
