# /explain-code
自分の書いた（AIに書かせた）コードを後から理解するためのコマンド。
「これ何やってるコードだっけ？」を解消して、メンテできる状態を保つ。

## 実行手順

### Step 0: 対象確認
- 説明してほしいファイル・関数・処理を確認

### Step 1: コード解説（初心者にも分かる言葉で）
- このコードが何をするか（1行で）
- どういう流れで動くか（ステップごと）
- なぜこの書き方なのか
- 触ると危ない箇所はどこか

### Step 2: 図解・たとえ
複雑な処理は身近なたとえで説明（勝貴くんが理解しやすいように）。

### Step 3: 改善・注意点
- もっとシンプルにできる箇所
- 将来バグになりそうな箇所

### Step 4: 完了報告
「このコードは要するに〇〇するもの」という一言サマリー。
AGENT_CONTEXT.mdに残すべきメモがあれば提案。
