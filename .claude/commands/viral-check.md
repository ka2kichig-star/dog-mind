# /viral-check
書いた投稿が「バズるか」を投稿前にチェックして改善するコマンド。
2.7万いいねの実績を再現性に変える。

## 実行手順

### Step 0: 投稿文の受け取り
- バズらせたい投稿の下書きを貼り付けてもらう
- 媒体を確認（Threads / X / Instagram）

### Step 1: バズ要素チェック（報告してから進む）
- [ ] 冒頭1行でスクロールを止められるか
- [ ] 共感 or 驚き or 学びのどれかがあるか
- [ ] 「自分ごと」と思える内容か
- [ ] 続きが気になる / 保存したくなる要素があるか
- [ ] 長すぎず読みやすいか
- [ ] コメントしたくなる余白があるか

### Step 2: 弱点の指摘
バズりにくい原因を正直に指摘。

### Step 3: 改善案（3パターン）
- 冒頭を強くした版
- 共感を強めた版
- 学び・実用性を強めた版

### Step 4: 完了報告
「このままなら△△、改善するなら□□」を提示。
徳ポイント哲学トーンとの相性も見る。
