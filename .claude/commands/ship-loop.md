# /ship-loop
リリース前の最終確認からデプロイ後の見守りまで一気通貫で回すループ。
「これ世に出して大丈夫か」を全部やる。

## このループがやること
```
verify-app（最終チェック・GO/HOLD判定）
　↓ HOLD → 止まって問題を報告
　↓ GO
release-note（リリースノート生成）
　↓
commit-push-pr（デプロイ）
　↓
babysit（デプロイ完了まで見守り）
　↓
完了報告
```

## 実行手順

### Step 0: 状態引き継ぎ
- `AGENT_CONTEXT.md` を読んで現在のバージョン・変更内容を把握
- リリース対象プロジェクトを確認
- 「現在の状態：〇〇」を報告してからループ開始

### Step 1: 最終検証フェーズ
`/verify-app` の手順に従う：
- 全機能チェックリスト実施
- **判定がHOLDなら即停止してブロッカーを報告**（無理にリリースしない）
- GOなら次へ

### Step 2: リリースノート生成フェーズ
`/release-note` の手順に従う：
- コミット履歴から変更内容を分類
- ユーザー向け / GitHub向け / SNS向けの3パターン生成

### Step 3: デプロイフェーズ
`/commit-push-pr` の手順に従う：
- コミット → push → デプロイ実行

### Step 4: 見守りフェーズ
`/babysit` の手順に従う：
- デプロイログを監視
- エラー・ハングを検知したら即報告

### Step 5: ループ完了報告
```
🚀 リリース完了
- バージョン：vX.X.X
- リリースノート：生成済み（3パターン）
- デプロイ：成功 / 失敗
- 本番動作：確認推奨URL
```
