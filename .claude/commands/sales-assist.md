# /sales-assist
HAYAMISEの営業メッセージ・提案書・フォローアップ文を生成するコマンド。

## 対象
HAYAMISE（サロン・飲食店向けサブスク型Web制作 ¥2,200〜¥6,600/月）

## 実行手順

### Step 0: 状況確認
以下を確認（未指定なら確認する）：
- 営業先の業種（美容院 / ネイル / カフェ / 飲食店など）
- 接触フェーズ（初回アプローチ / 提案 / フォロー / クロージング）
- 媒体（DM / LINE / 対面 / メール）

### Step 1: 相手のペイン分析
業種ごとの共通課題を分析して報告：
- 今どんなWeb集客をしているか（予測）
- どこに不満があるか（予測）
- HAYAMISEで解決できること

### Step 2: 文章生成（3パターン）

**パターンA**: ソフトアプローチ（いきなり売らない）
まず価値提供・共感から入る。

**パターンB**: 直接提案（メリット先行）
「今より〇〇円でWebが持てます」を前面に。

**パターンC**: 実績訴求（ろじうらポートフォリオ活用）
「こんなサイト作りました」を見せて興味喚起。

### Step 3: フォローアップ文
返信がなかった場合の追撃メッセージも生成。

### Step 4: 完了報告
3パターン + フォロー文をコピペ用で出力。
使い分けのアドバイスも添える。
