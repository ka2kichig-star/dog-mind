# /start-day-loop
朝イチで全プロジェクトの状況を把握して今日やることを決めるループ。
「今日何からやろう」を3秒で解決する。

## このループがやること
```
morning-brief（全プロジェクト状況サマリー・今日のタスク整理）
　↓
最優先タスクに対応するコマンドを提案
　↓
そのまま着手するか確認
```

## 実行手順

### Step 0: 状態引き継ぎ
- `AGENT_CONTEXT.md` を読んで全プロジェクトの現状を把握
- 今日の日付・曜日・使える時間を確認

### Step 1: 状況把握フェーズ
`/morning-brief` の手順に従う：
- 全プロジェクトの緊急度を一覧化
- 使える時間に合わせてタスクを並べる

### Step 2: 最初の一手の提案
今日の最優先タスクを1つだけ選んで提示：
```
🎯 今日の最初の一手
タスク：〇〇
使うコマンド：/[コマンド名]
推定時間：〇分
理由：△△だから今やるのが最適
```

### Step 3: 着手確認
「このまま /[コマンド] を実行する？」とユーザーに確認。
GOなら該当コマンドのループに自動で繋ぐ。
