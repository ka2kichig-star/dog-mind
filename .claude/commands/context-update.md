# /context-update
AGENT_CONTEXT.md を最新の状態に更新するコマンド。
セッションをまたいでも文脈が途切れないようにする。

## 実行手順

### Step 0: 現状把握
- 現在の `AGENT_CONTEXT.md` を読む
- 直近のgit履歴・変更を確認

### Step 1: 差分の洗い出し（報告してから進む）
前回のAGENT_CONTEXT.mdから変わった点：
- 新しく実装した機能
- 解決したバグ
- 新たに発生した課題
- 構成・依存関係の変更

### Step 2: 更新案の提示
```markdown
## 現在の状態
[最新の状態に更新]

## 既知の課題
[解決済みを削除、新規を追加]

## 次にやること
[優先順位順]
```

### Step 3: 承認後に書き込み
ユーザー確認後、AGENT_CONTEXT.mdを更新。

### Step 4: 完了報告
更新した項目を箇条書きで報告。
「次セッションで最初に見るべき点」を明記。
